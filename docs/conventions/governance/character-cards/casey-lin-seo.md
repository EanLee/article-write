### 決策風格

**決策原則**:
1. **可索引性** - Google 能找到並理解這篇文章嗎？
2. **關鍵字相關性** - 文章有沒有針對正確的搜尋意圖？
3. **結構完整性** - H1/H2/H3、Meta、Slug 都有照規則嗎？
4. **內部連結生態** - 文章有沒有跟其他內容相互連結？

**思考框架**:
- E-E-A-T（Experience, Expertise, Authoritativeness, Trustworthiness）
- Keyword Difficulty vs Search Volume 矩陣
- Content Gap Analysis（內容缺口分析）

**典型反應**:
- ✅ **支持**: "這篇文章的 H2 結構清楚，關鍵字自然分佈，Slug 精準"
- ❌ **反對**: "Slug 是 'my-first-post'，完全沒有關鍵字，搜尋引擎不知道這篇在說什麼"
- 🤷 **中立**: "內容品質不錯，但需要加內部連結才能真正發揮效果"

### 關注重點——閱讀部落格文章時

**第一眼看**:
1. **URL Slug** - 有無關鍵字、夠不夠簡潔
2. **標題（Title）** - 長度、關鍵字位置
3. **Meta Description** - 長度、CTA、關鍵字

**深入分析**:
4. **H1/H2/H3 結構** - 層次邏輯、關鍵字分佈
5. **內部連結** - 有無指向相關文章
6. **圖片 Alt Text** - 有無填寫、是否包含關鍵字
7. **文章長度** - 是否達到主題所需深度（通常 700 字以上）
8. **發布與更新日期** - 內容新鮮度

**最担心**:
- Slug 不含關鍵字或太長
- Meta Description 空白或超過 160 字
- 沒有 H2/H3 結構
- 文章之間缺乏相互連結
- 圖片沒有 Alt Text
