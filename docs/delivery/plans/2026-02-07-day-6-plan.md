## 🎯 今日目標

**主要任務**: 建立可用的設定介面，讓使用者能夠設定並儲存路徑

**驗收標準**：
- [ ] 可透過 UI 選擇 Obsidian Vault 路徑
- [ ] 可透過 UI 選擇 Astro 專案路徑
- [ ] 路徑驗證正確（有效/無效提示）
- [ ] 設定可在 UI 中即時顯示

**不在範圍內**：
- ❌ 設定持久化（明天做）
- ❌ 複雜的驗證邏輯（基本驗證即可）
- ❌ UI 美化（能用就好）
- ❌ 錯誤處理優化（基本錯誤即可）

## 📋 詳細任務拆解

### Task 1: 建立 Settings.vue 基礎結構 (1.5 小時)

**目標**: 建立設定頁面的基本架構

**子任務**：
- [ ] 建立 `src/components/Settings.vue` 檔案
- [ ] 設計基本 UI 布局（2 欄式：側邊欄 + 主內容區）
- [ ] 建立 Tab 切換機制（一般設定、Git 設定）
- [ ] 整合到主應用程式路由

**驗收**：
- 可從主選單開啟設定頁面
- 可在不同 Tab 之間切換
- UI 布局清晰可用

**參考**：
- 現有的 `SettingsPanel.vue`（可參考但需重構）
- 使用 Vue 3 Composition API

---

### Task 2: Obsidian Vault 路徑選擇器 (2 小時)

**目標**: 實作 Obsidian Vault 路徑選擇功能

**子任務**：
- [ ] 建立路徑輸入框（顯示當前路徑）
- [ ] 建立「瀏覽」按鈕（使用 Electron dialog）
- [ ] 實作 IPC 通訊（renderer → main）
- [ ] 實作路徑驗證邏輯（檢查目錄是否存在）
- [ ] 顯示驗證結果（✓ 有效 / ✗ 無效）

**驗收**：
- 點擊「瀏覽」可開啟檔案選擇器
- 選擇的路徑會顯示在輸入框
- 路徑驗證正確（有效/無效）
- 無效路徑顯示錯誤訊息

---

### Task 3: Astro 專案路徑選擇器 (1.5 小時)

**目標**: 實作 Astro 專案路徑選擇功能

**子任務**：
- [ ] 建立路徑輸入框（顯示當前路徑）
- [ ] 建立「瀏覽」按鈕（使用 Electron dialog）
- [ ] 複用 Task 2 的 IPC 通訊
- [ ] 實作路徑驗證邏輯（檢查目錄是否存在）
- [ ] 顯示驗證結果（✓ 有效 / ✗ 無效）

**驗收**：
- 點擊「瀏覽」可開啟檔案選擇器
- 選擇的路徑會顯示在輸入框
- 路徑驗證正確（有效/無效）
- 無效路徑顯示錯誤訊息

---

### Task 4: 路徑驗證邏輯強化 (1.5 小時)

**目標**: 實作更完善的路徑驗證

**子任務**：
- [ ] **Obsidian Vault 驗證**：
  - [ ] 檢查目錄是否存在
  - [ ] 檢查是否為有效的 Obsidian Vault（包含 `.obsidian` 資料夾）
  - [ ] 顯示清楚的錯誤訊息
  
- [ ] **Astro 專案驗證**：
  - [ ] 檢查目錄是否存在
  - [ ] 檢查是否為有效的 Astro 專案（包含 `astro.config.*`）
  - [ ] 顯示清楚的錯誤訊息

**驗收**：
- Obsidian Vault 驗證正確（有 .obsidian 資料夾）
- Astro 專案驗證正確（有 astro.config.*）
- 錯誤訊息清楚明確
- UI 即時顯示驗證結果

---

### Task 5: 設定狀態管理 (1 小時)

**目標**: 在 Vue 中管理設定狀態

**子任務**：
- [ ] 建立 `useSettings` Composable
- [ ] 管理 Obsidian Vault 路徑狀態
- [ ] 管理 Astro 專案路徑狀態
- [ ] 管理驗證狀態（loading, valid, error）
- [ ] 實作即時驗證（路徑變更時自動驗證）

**驗收**：
- 路徑狀態正確管理
- 驗證狀態正確管理
- 路徑變更時自動驗證
- Loading 狀態正確顯示
